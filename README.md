# dataset/

Place the downloaded Kaggle CSV file here:

1. Go to https://www.kaggle.com/datasets/kyanyoga/sample-sales-data
2. Download `sales_data_sample.csv`
3. Place it in this folder as: `dataset/sales_data_sample.csv`

The CSV file is not included in this repository (per Kaggle's terms of
use, redistribute only through the official dataset page). See
`sql/02_import_dataset.sql` for import instructions once the file is here.
